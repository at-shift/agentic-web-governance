Agentic Web Governance uses separate licenses for documentation and source
code. A file-level SPDX identifier overrides the default rules below.

[Creative Commons Attribution 4.0 International License](LICENSES/CC-BY-4.0.txt),
including:

- Markdown files (`*.md`);
- specifications, RFCs, profiles, mappings, diagrams, and source notes;
- other prose whose primary purpose is documentation.

SPDX-License-Identifier: CC-BY-4.0

When attribution is required, credit "Agentic Web Governance contributors" and
link to <https://github.com/at-shift/agentic-web-governance> where reasonably
practicable.

## Source code

All source code and executable examples are licensed under the
[GNU General Public License, version 2 or any later version](LICENSES/GPL-2.0-or-later.txt).
This includes future implementation code, tests, build scripts, and supporting
program files unless a file states otherwise.

SPDX-License-Identifier: GPL-2.0-or-later

New source files should include the following identifier in a comment using the
syntax appropriate for that file type:

```text
SPDX-License-Identifier: GPL-2.0-or-later
```

## Code in documentation

Code listings and snippets embedded in documentation may be used under either
CC BY 4.0 or GPL-2.0-or-later, at the recipient's choice. This avoids making a
documentation excerpt difficult to reuse in an implementation.
